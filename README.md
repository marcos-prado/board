# Criação de um Board de Tarefas
## Projeto para a criação de um board de tarefas em Java, onde foi realizado diversas etapas de desenvolvimento, tais como:
 - Planejamento e estruturação.
 - Implementação de funcionalidades como gerenciamento de dados.
 - Conexão com o banco de dados utilizando o Mysql.
 - Integração entre camadas, seguindo as boas práticas de programação.
